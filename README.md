# FREE VIP ACCESS Telegram Bot

A Telegram bot built with **python-telegram-bot**, deployable on **Railway**.

## 🚀 Features
- User signup flow (PAY ➜ SHARE ➜ VIP Approval)
- Admin commands `/approve` and `/check`
- SQLite database
- Environment-based token (safe)
- Works with Railway one-click deploy
